# Changelog

## 0.6.0.dev0 — unreleased MVP Preview

- Complete local workflow: workload selection, deterministic or imported AI
  proposals, sealed plans, approval, separate correctness validation, real builds,
  calibrated paired timing, held-out confirmation and JSON/Markdown/local HTML.
- Ten workloads and 31 trusted MVP experiment panels. The original research
  command retains its 17-panel family. No arbitrary AI execution or rewriting.
- Public repository preparation, community/security documents and isolated
  package checks. Existing MIT license retained; ownership review remains the
  publishing owner's responsibility.
- macOS/Apple Silicon compatibility implementation and capability reporting;
  actual Mac M4 verification remains pending until it runs on real hardware.
- Multi-platform CI configuration. A configured workflow is not evidence of a
  successful GitHub Actions run.

No independently verified improvement has been found. WSL2 measurement quality
is unvalidated, native Linux scientific validation is pending, and research
cannot create production presets. This milestone does not complete Phase 6.
